网速测试 —— 双击就能用的测速小工具（界面 + 命令行）
================================================================================

【这是什么】
  多线程从镜像站/测速点同时拉数据、打数据，逐秒读网卡计数器算真实速率，
  边测边画曲线。稳不稳、跑没跑满，一眼就能看见。

  · 下载 / 上传 / 延迟，想测哪个勾哪个
  · 可以一次勾好几块网卡一起测，分别看每块，也看合计
  · **不需要管理员权限**，双击就跑
  · 下载的数据读进内存就扔掉，**不落盘**，不占硬盘

【怎么用】
  双击 网速测试.exe

  ① 上面「测什么」勾选：下载 / 上传 / 延迟 (ping)
     勾几项就测几项，**一项一项依次跑**（不是同时抢带宽 —— 同时跑的话两个数都只有一半）
     ⚠ 一项都不勾的话，「开始测试」是灰的，点不了

  ② 「设置」
     时长        每项计时几秒，默认 15
     线程数      每块网卡起几个并发，默认 = 逻辑处理器数
     预热        正式计时前先跑几秒把连接建好，不计入统计，默认 3
     套餐        宽带档位，用来算「跑到了几成」，默认 1000
     上传落点    上传数据往哪儿打，见下面「关于上传」

  ③ 「网卡（可多选）」勾要测的网卡。改动过网卡（插了 USB 网卡之类）点「重新扫描网卡」。
     · 只有**带网关**的网卡能测；没有网关的（比如 Hyper-V 虚拟交换机）勾了也拉不动，
       会标注「无网关·测不了」
     · 标「虚拟网卡」的多半是代理/虚拟机网卡，测出来的是隧道不是物理链路
     ⚠ **多块网卡如果走的是同一个路由器/同一条宽带，合计不会超过那条线的总带宽** ——
       只是把同一条管子分成几股，不是真的翻倍。要看到合计翻倍，得是两条独立的上游。

  ④ 回车 或 点「开始测试」；「停止」随时中断（连接立刻断，不会偷偷继续占带宽）

【怎么看结果】

  曲线图
    · 一块网卡一条线，颜色按固定顺序取（蓝/橙/青/黄…），左上角图例带名字和当前值
    · 灰虚线 = 套餐参考线；左上角大数字 = **当前合计**
    · 曲线平 = 稳；锯齿 = 上游在抖动
    · 从下载切到上传时曲线会重画（每次只画当前这一项的曲线）

  「判读」（结果区右边，带颜色 + 符号）
    ✓ 绿 = 跑满或接近套餐 / 很稳     ⚠ 黄 = 有东西在拖后腿     × 红 = 确实有问题
    它还会对比**空闲延迟**和**满载延迟**：满载时延迟不涨说明光猫/路由器扛得住；
    涨很多（bufferbloat）说明有人在满载时别人打游戏会卡。

  报告里这些数别搞混
    「一次拉了 / 一次发出」= 网卡计数器口径，是这条线路真实的吞吐
    「实际吞吐」= 程序真正读进来/写出去的字节数
                 比上面少一截是**正常的** —— 收工那一刻还有一部分压在收发缓冲里没走完
    「自洽核对」= 网卡差值反推的速率 vs 逐秒采样平均，两者差在 1% 内算正常

【关于上传】
  上传需要一个「愿意收 POST 数据然后扔掉」的服务器。国内能公开这么干的测速点基本都关掉了
  （中科大的服务器返回 500，Ookla 的接口 403），所以默认用的是 Cloudflare：

      https://speed.cloudflare.com/__up

  ⚠ 它走国际线路，**数字比你真实的上传带宽保守，而且波动大**。
    想测准，把「上传落点」改成你自己国内能收 POST 的地方 —— 云服务器、对象存储、
    自建的一个丢弃 body 的接口都行，不用改代码，填进框里就生效。
    落点必须：接受 POST + 不鉴权（或把鉴权头也做进去）+ 收下 body 直接丢弃。

【多网卡】
  勾多块网卡 → 每块各起 N 个线程同时测 → 报告和曲线都分别给每块网卡的数据，再给合计。
  注意：一台机器上能拿来测的网卡不多（虚拟网卡、没网关的网卡都排除），
  你机器上通常只有一块真正能上外网的。

【历史记录】
  每跑完一次就自动追加一行到 网速测试\历史记录.jsonl，点「历史记录」按钮查看：
    · 上面列表  时间 / 测了哪几项 / 网卡 / 下载 / 上传 / 空闲延迟 / 满载延迟
    · 下面详情  那次完整的报告原文
    · 按钮      刷新 · 导出 CSV（Excel 能直接打开）· 打开所在文件夹 · 清空历史
  也可以直接把 exe 拖到命令行加 --history 启动。

【命令行模式】
  网速测试.exe --cli --seconds 15 --threads 16 --out 报告.txt
  网速测试.exe --cli --list-nics            看看有哪些网卡能选

    --download / --no-download   测 / 不测下载（默认测）
    --upload                     测上传（默认不测）
    --ping / --no-ping           测 / 不测延迟（默认测）
    --upload-url <地址>          上传落点
    -s / --seconds <秒>          计时时长，默认 15
    -t / --threads <n>           每块网卡的并发，默认 = 逻辑处理器数
    -w / --warmup <秒>           预热秒数，0 = 关
    -p / --plan <Mbps>           套餐
    --nic "网卡名"               指定网卡，可写多次（多块 = 同时测）
    -o / --out <文件>            报告另存一份到文件
    --help / -h                  帮助

  小提示：从 cmd 直接跑，输出可能攒到你敲下一条命令时才刷出来 ——
  这是 GUI 子系统进程附着到父控制台的通病，不是卡住了。
  管道里跑（| more、> 文件）或直接用 --out，都没这个问题。

【重新编译】
  装了 .NET 10 SDK 就能编：双击 编译.bat。
  源码在 源码\ 下（C# / WinForms，**零第三方依赖**，离线也能编）。
  产物是「依赖框架的单文件 exe」，约 250 KB，需要机器上有 .NET 10 桌面运行时。

【想换下载源】
  源码\TrafficEngine.cs 里的 Sources 数组，8 个 URL 都是 Ubuntu 镜像站的 ISO。
  镜像站把老 ISO 删掉就会 404（那个 24.04.4 迟早会被替换），到时候换新的就行。
  某个源临时抽风不会让测试挂掉，会自动歇一下重来。

【出问题怎么办】
  程序崩了会在 exe 旁边写一份 错误日志.txt（带完整堆栈），发我看看。
